# Fundacja Kod dla Dzieci

> Tworzymy technologie, które pomagają dzieciom z porażeniem mózgowym i innymi niepełnosprawnościami

## 🎯 Misja

Fundacja Kod dla Dzieci powstała, aby wspierać rozwój technologii wspomagających komunikację, rehabilitację i edukację dzieci z porażeniem mózgowym oraz innymi niepełnosprawnościami. Tworzymy oprogramowanie open-source, urządzenia wspomagające i rozwiązania, które realnie zmieniają życie.

## 💡 Nasze projekty

### W trakcie rozwoju
- **EyeTalk** – komunikator sterowany wzrokiem dla dzieci z MPD
- **MotionPlay** – gry rehabilitacyjne oparte o czujniki ruchu
- **OpenAAC** – darmowy system komunikacji alternatywnej (AAC)

### Planowane
- Platforma wspierająca rodziców i terapeutów
- Biblioteki open-source dla twórców sprzętu wspomagającego
- Narzędzia do analizy postępu rehabilitacji

## 🤝 Jak pomóc

### Wolontariat techniczny
- Programowanie (Python, JavaScript, C++, Arduino)
- Projektowanie UX/UI dostępnych interfejsów
- Testowanie z użytkownikami końcowymi
- Dokumentacja techniczna

### Wolontariat nietechniczny
- Współpraca z terapeutami i rodzicami
- Testowanie rozwiązań z dziećmi
- Promocja i fundraising
- Organizacja wydarzeń

### Wsparcie finansowe
- Darowizny: konto bankowe fundacji
- 1,5% podatku (po uzyskaniu statusu OPP)
- Sponsoring sprzętu i licencji
- Granty na konkretne projekty
