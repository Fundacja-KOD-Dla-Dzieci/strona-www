Nasza misja

Wierzymy, że technologia może przybliżać dzieci do samodzielności i radości życia

Open Source

Wszystkie nasze projekty są open-source i dostępne dla każdego. Tworzymy technologie, które mogą być rozwijane przez społeczność.

Dostępność

Projektujemy rozwiązania z myślą o dostępności. Każde nasze narzędzie jest testowane z użytkownikami końcowymi.

Społeczność

Budujemy społeczność wolontariuszy, terapeutów, rodziców i programistów, którzy wspólnie tworzą lepsze rozwiązania.

Nasze projekty

Tworzymy technologie, które realnie zmieniają życie dzieci

EyeTalk

Komunikator sterowany wzrokiem dla dzieci z porażeniem mózgowym. Umożliwia komunikację poprzez śledzenie ruchu gałek ocznych.

JavaScript WebRTC Accessibility
GitHub Demo

OpenAAC

Darmowy system komunikacji alternatywnej (AAC) z biblioteką symboli i funkcjami personalizacji dla różnych potrzeb użytkowników.

React PWA AAC
GitHub Demo

MotionPlay

Gry rehabilitacyjne oparte o czujniki ruchu. Wspierają rozwój motoryczny i koordynację u dzieci z niepełnosprawnościami.

Unity Arduino Rehabilitation
GitHub Demo
